Tiled codes

Level files use the cells.tsj tileset. A cell's GID is its tile id + 1; GID 0 is open air. Only the top four bits of a GID are flags.

CellTile idGIDModels
ground01ground
tree12forest-floor
water23water
rock34grey-rock
blackrock45black-rock
station56ground with track; the station building beside it
ramp67ramp
ramp_blackrock78unused (one ramp type since D9.8 revision)
track89track-straight, track-curve; track-ramp on ramps

Ramp direction is stored in Tiled's flip flags. The unrotated ramp tile rises toward north (−y); the ramp model rises toward east (+x), so it is rotated about z to match:
